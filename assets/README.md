# Application assets

Reusable illustrations used by the interface and learning activities belong in:

```text
assets/
  images/
    illustrations/
      chemistry/
        elements/    # Chemical element illustrations (PNG)
```

Group future illustrations by subject and topic using the same structure.
Lesson text and question banks belong in `data/subjects/`, not in assets.

Book and notebook scans are source materials, not application assets. Do not
commit them. If needed while authoring lessons, keep them in the ignored
`source-materials/` directory at the project root. Published activities must
not reference that directory.
